# Grok Bot Icon 中文提示词

将人物或角色图片转换为黑色胶囊眼、圆脸、倾斜近景构图的极简 2D 机器人头像。

## 提示词

完整中文提示词见 [prompt.zh-CN.md](prompt.zh-CN.md)。

## 使用方法

1. 复制提示词全文到支持图片输入与图像生成的工具中。
2. 附上希望转换的人物或角色图片。
3. 如果图片中有多个人物，请明确指定转换对象。
